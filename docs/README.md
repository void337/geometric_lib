# Документация библиотеки "geometric_lib"

## Общее описание решения

Библиотека предоставляет набор математических функций для вычисления площадей и периметров геометрических фигур - квадрата и круга.

## Описание функций

### Модуль `circle.py`

#### Функция `area(r)`
```python
def area(r):
    '''
    Принимает радиус окружности и возвращает площадь
    
    Параметры:
        r (int/float): радиус окружности
    
    Возвращаемое значение:
        area (float): площадь окружности
    ''' 
    return math.pi * r * r
```

#### Функция `perimeter(r)`
```python
def perimeter(r):
    '''
    Принимает радиус окружности и возвращает длину окружности
    
    Параметры:
        r (int/float): радиус окружности
    
    Возвращаемое значение:
        perimeter (float): длина окружности
    ''' 
    return 2 * math.pi * r
```

### Модуль `square.py`

#### Функция `area(a)`
```python
def area(a):
    '''
    Принимает сторону квадрата и возвращает площадь
    
    Параметры:
        a (int/float): сторона квадрата
    
    Возвращаемое значение:
        area (int/float): площадь квадрата
    ''' 
    return a * a
```

#### Функция `perimeter(a)`
```python
def perimeter(a):
    '''
    Принимает сторону квадрата и возвращает периметр
    
    Параметры:
        a (int/float): сторона квадрата
    
    Возвращаемое значение:
        perimeter (int/float): периметр квадрата
    ''' 
    return 4 * a
```
### Модуль `triangle.py`

#### Функция `area(a, h)`
```python
def area(a, h):
    '''
    Принимает сторону и высоту треугольника и возвращает площадь
    
    Параметры:
        a (int/float): сторона треугольника
        h (int/float): высота треугольника
    
    Возвращаемое значение:
        area (int/float): площадь треугольника
    ''' 
    return a * h / 2
```

#### Функция `perimeter(a, b, c)`
```python
def perimeter(a, b, c):
    '''
    Принимает стороны треугольника и возвращает периметр
    
    Параметры:
        a (int/float): первая сторона треугольника
        b (int/float): вторая сторона треугольника
        c (int/float): третья сторона треугольника
    
    Возвращаемое значение:
        perimeter (int/float): периметр треугольника
    ''' 
    return a + b + c
```

### Модуль `rectangle.py`

#### Функция `area(a, b)`
```python
def area(a, b):
    '''
    Принимает стороны прямоугольника и возвращает площадь
    
    Параметры:
        a (int/float): первая сторона прямоугольника
        b (int/float): вторая сторона прямоугольника
    
    Возвращаемое значение:
        area (int/float): площадь прямоугольника
    ''' 
    return a * b
```

#### Функция `perimeter(a, b)`
```python
def perimeter(a, b): 
    '''
    Принимает стороны прямоугольника и возвращает периметр
        Параметры:
            a (int/float): первая сторона прямоугольника
            b (int/float): вторая сторона прямоугольника
        Возвращаемое значение:
            perimeter (int/float): периметр прямоугольника
    ''' 
    return 2*a + 2*b 
```

# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
